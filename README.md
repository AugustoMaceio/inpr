# Introdução à Programação em JavaScript

Este repositório reúne exercícios de introdução à programação em JavaScript do Prof. Augusto, do IFAL - Maceió.

## Conteúdo

- `repeticao/README.md` — Aula de estruturas de repetição em JavaScript
- `funcoes/README.md` — Aula de definição e chamada de funções em JavaScript

## Como usar

1. Abra a pasta do repositório.
2. Leia o conteúdo de cada aula:
   - `repeticao/README.md`
   - `funcoes/README.md`
3. Execute os exercícios no Node.js conforme indicado em cada aula.

## Estrutura do repositório

- `repeticao/` — exercícios sobre `while`, `do...while`, `for`, `break` e `continue`
- `funcoes/` — exercícios sobre definição de funções, parâmetros, retorno e chamada de funções

## Execução básica

Se você quiser executar os exemplos, instale as dependências e rode os scripts:

```bash
npm install
```

Para rodar um exercício:

```bash
node repeticao/nome_do_arquivo.js
node funcoes/nome_do_arquivo.js
```
